# SoftwareEng1

Setup guide

- Make a new branch as your name

- Clone to your local computer
    - You might need to install git commands to your computer
    - https://github.com/git-guides/install-git

- install docker
  - This is how we will run our code
  - https://www.docker.com/products/docker-desktop/

- install PGAdmin
  - This is how we will be able to see out data base
  - Use the one for your machine and not the container 
  - https://www.pgadmin.org/download/
